ZART — GitHub Pages demo

Эта версия подготовлена для публикации так же, как AutoTex: статический сайт на GitHub Pages.

Публикация:
1. Создай GitHub repository, например zart-store.
2. Распакуй ZIP и загрузи ВСЕ файлы и папку assets в корень репозитория (не загружай сам ZIP).
3. Открой Settings → Pages.
4. В разделе Build and deployment выбери Deploy from a branch.
5. Branch: main; Folder: / (root); нажми Save.
6. Подожди завершения публикации и открой ссылку GitHub Pages.

Главная: index.html
Демо-админка: admin.html

ВАЖНО: это только демонстрация для просмотра. Каталог, корзина, регистрация, заказы и админские изменения хранятся в localStorage браузера. Они не синхронизируются между посетителями и не приходят продавцу. Нет реальной авторизации, серверной базы и онлайн-оплаты. Не используй для настоящих заказов. Для коммерческого запуска потребуется серверная версия Node.js с постоянной базой данных и защищённой админкой.
