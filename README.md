# ZART — интернет-магазин одежды

Готовый магазин: витрина, каталог, карточка товара, корзина, оформление заказа, регистрация покупателя и админ-панель с редактированием товаров.

**Языки:** армянский (главный), русский, английский — переключатель в правом верхнем углу.
**Стиль:** чёрный / белый / золото, орнаментальная армянская графика.
**Валюта:** армянский драм (֏).

---

## 1. Как открыть

Распакуй архив и открой файл **index.html** двойным щелчком — магазин работает прямо в браузере, без установки и сервера.

Админ-панель: файл **admin.html** (или ссылка «Админка» в подвале сайта).

**Пароль по умолчанию: `zart2026`** — меняется в админке: «Настройки» → «Новый пароль».

## 2. Что есть в магазине

- Каталог с категориями и фильтрами
- Карточка товара: фото, описание, цена, выбор размера, количество
- Корзина с пересчётом суммы и доставки (бесплатно от 25 000 ֏)
- Оформление заказа: контакты, адрес, доставка (Ереван / регионы / самовывоз), оплата (наличными или переводом)
- Номер заказа и страница «спасибо»
- Регистрация и вход покупателя, история его заказов
- Страницы «О нас» и «Контакты»
- Адаптив под телефон

## 3. Админ-панель

- **Обзор** — сумма заказов, количество заказов и товаров
- **Товары** — добавить, изменить, удалить: названия и описания на трёх языках, цена, старая цена, остаток, размеры, категория, метка (new / скидка / bestseller), фото (ссылка или загрузка с компьютера)
- **Категории** — создание и правка разделов
- **Заказы** — состав, клиент, адрес, сумма; статус меняется в таблице (новый → подтверждён → отправлен → выполнен / отменён)
- **Клиенты** — зарегистрированные покупатели и заказы без аккаунта
- **Настройки** — телефон, Instagram, почта, адреса, стоимость доставки, порог бесплатной доставки, пароль
- **Резервная копия** — выгрузка и загрузка всех данных в JSON, сброс к демо-данным

## 4. Где менять фото

Фотографии лежат в папке `assets/img/`. Можно заменить файл с тем же именем — или загрузить своё фото прямо в админке в форме товара (оно автоматически уменьшится).

**Важно:** все фото в архиве — сгенерированные изображения-заглушки под стиль бренда. Перед запуском замени их на реальные фотографии твоих вещей: снимай на тёмном фоне с одним источником света — тогда карточки не выбьются из дизайна.

## 5. Демо-режим и реальные заказы

Сейчас сайт работает как статическая демо-версия: товары, заказы, клиенты и правки из админки сохраняются **в браузере на этом устройстве**. Это значит:

- твои изменения в админке видит только этот браузер;
- заказ, оформленный на телефоне покупателя, не попадёт в твою админку;
- оплата не подключена.

Для настоящего магазина с оплатой и заказами с любых устройств нужен сервер (база данных + личный кабинет + платёжный провайдер: ArCa / Idram / Telcell, либо Stripe). Сайт к этому подготовлен: вся логика товаров и заказов собрана в одном месте, поэтому его можно подключить к готовой платформе (WooCommerce, Shopify) или к собственному бэкенду — дизайн и вёрстка останутся этими.

## 6. Как выложить в интернет

Любой хостинг статических сайтов: загрузить папку целиком (или перетащить её в Netlify / Cloudflare Pages), затем привязать домен. Никаких настроек не требуется.
